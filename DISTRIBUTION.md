# Distribution playbook — path to 1,000+ users

Use this after each deploy. Organic SEO compounds; distribution creates the first spike.

## 1) Search engines (highest long-term ROI)

1. [Google Search Console](https://search.google.com/search-console) → Add `https://www.devutil.dev`
2. Prefer **HTML tag** verification → paste code into Vercel env as `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` → redeploy
3. Submit sitemap: `https://www.devutil.dev/sitemap.xml`
4. URL Inspection → request indexing for:
   - `/`, `/json-formatter`, `/sql-formatter`, `/yaml-json-converter`, `/cron-generator`
   - `/markdown-preview`, `/json-csv-converter`, `/uuid-generator`
   - `/guides`, `/guides/format-json-online`, `/guides/cron-expression-examples`
5. Repeat in [Bing Webmaster Tools](https://www.bing.com/webmasters)

## 2) Launch posts (first 7 days)

Share https://www.devutil.dev/whats-new with this angle:

> Free privacy-first developer toolbox — 22 utilities (JSON/SQL/XML, YAML↔JSON, cron, Markdown, UUID v4/v7). Everything runs in your browser. No login. No uploads.

Post to:
- Reddit: r/webdev, r/programming, r/selfhosted, r/SideProject (follow each sub’s rules)
- Indie Hackers
- Product Hunt (ship as “DevUtil”)
- Twitter/X + LinkedIn with 1–2 tool GIFs/screenshots
- Dev.to / Hashnode short post linking guides

## 3) Directories & backlinks

Submit:
- AlternativeTo, SaaSHub, Toolify, There’s An AI For That (as utility, not AI), Awesome lists PRs
- GitHub topics: `developer-tools`, `json-formatter`, `privacy`, `nextjs`

## 4) Weekly product loop

From Umami/GA:
1. Top landing pages → improve titles/H1s and FAQ
2. High bounce tools → add sample data + clearer CTA
3. Low discovery tools → add homepage “Popular” + related links from JSON/SQL

## Target

- **Week 1:** 100–300 users from launch posts + friends
- **Month 1–3:** compound SEO from tools + guides toward **1,000+ monthly users**
